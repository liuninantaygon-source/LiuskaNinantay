# BCP - Proyecto de Diseño Web

## Descripción
Página web académica de demostración sobre servicios bancarios del BCP, desarrollada para la Unidad Didáctica 2.

## Tecnologías utilizadas
- HTML5 con estructura semántica.
- CSS3 con selectores, cajas flotantes, transiciones, animaciones y diseño responsivo.
- Audio y video locales.
- Video externo integrado mediante `iframe`.
- Metaetiquetas SEO básicas.

## Archivos del proyecto
- `index.html`: estructura de la página.
- `css/style.css`: estilos y diseño responsivo.
- `video.mp4`: video local.
- `bcp-peru.mp3`: audio local.
